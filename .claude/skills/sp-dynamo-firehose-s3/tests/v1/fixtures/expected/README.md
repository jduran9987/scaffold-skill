# orders

Pipeline to ingest orders.

Generated by the sp-dynamo-firehose-s3 skill.

## Bronze

Loads each record Firehose writes to S3, unchanged, into a single VARIANT column, along with when it was loaded and which file it came from. One row per record. Each run reads only files it has not read before.

| Target | Table |
|---|---|
| dev | `dev.bronze.orders` |
| qa | `qa.bronze.orders` |
| uat | `uat.bronze.orders` |
| prod | `prod.bronze.orders` |

| Column | Type | Description |
|---|---|---|
| `data` | VARIANT | DynamoDB change event as delivered by Firehose from the table's Kinesis stream. |
| `_ingested_at` | TIMESTAMP | Time the bronze job loaded the record. |
| `_file_path` | STRING | S3 path of the Firehose file the record came from. |
| `_file_modification_time` | TIMESTAMP | Time the Firehose file the record came from was last modified in S3. |

## Silver

Reads new bronze rows and flattens each DynamoDB change event into typed columns. One row per change. Inserts and modifies take their values from the item after the change, and removes from the item before it. Key columns always come from the event's keys.

| Target | Table |
|---|---|
| dev | `dev.silver.orders` |
| qa | `qa.silver.orders` |
| uat | `uat.silver.orders` |
| prod | `prod.silver.orders` |

| Column | Type | Description |
|---|---|---|
| `id` | INT | Order identifier. |
| `created_at` | TIMESTAMP | UTC timestamp when an order was created. |
| `amount` | DECIMAL(22, 2) | Order amount in dollars. |
| `status` | STRING | Order status. |
| `address__city` | STRING | City from where the order was placed. |
| `address__state` | STRING | State from where the order was placed. |
| `address__zip_code` | STRING | Zip code from where the order was placed. |
| `_event_name` | STRING | DynamoDB change type: INSERT, MODIFY, or REMOVE. |
| `_event_id` | STRING | Unique ID of the DynamoDB change event. |
| `_event_timestamp` | TIMESTAMP | Approximate time DynamoDB made the change, from the event's ApproximateCreationDateTime. |
| `_ingested_at` | TIMESTAMP | Time the bronze job loaded the record. |
| `_file_path` | STRING | S3 path of the Firehose file the record came from. |
| `_file_modification_time` | TIMESTAMP | Time the Firehose file the record came from was last modified in S3. |

## Gold

Merges silver changes into one row per primary key, keeping the most recent change. A newer change replaces the stored row, and an older one is ignored. Items deleted in DynamoDB remain as rows whose `_event_name` is `REMOVE`.
